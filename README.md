# مِهاد — الموقع التفاعلي (نقلثون 5)

نموذج تفاعلي لتطبيق **مِهاد**: يخطط رحلتك في الرياض بالحافلة والمترو والسيارة، ويقارن الخيارات بالوقت والتكلفة والازدحام، وينبّهك عند تأخر الحافلة ويقترح بديلًا أسرع.

## محتويات المجلد

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع كامل: الواجهات والتنقل والمساعد ولوحة المحاكاة |
| `api/chat.js` | دالة الذكاء الاصطناعي (تعمل على Vercel فقط) |
| `assets/Alexandria.ttf` | خط الموقع (رخصة OFL مرفقة) |

## التجربة على جهازك (VS Code)

1. افتح المجلد في VS Code: **File ← Open Folder ← mihad-web**.
2. ثبّت إضافة **Live Server** من قائمة الإضافات (`Ctrl+Shift+X`).
3. اضغط بالزر الأيمن على `index.html` واختر **Open with Live Server**.

> على جهازك يعمل المساعد بالوضع الاحتياطي (ردود جاهزة لنفس السيناريو). الذكاء الاصطناعي الحقيقي يعمل بعد النشر على Vercel.

## مسار العرض

`01 الرئيسية ← 02a مِهاد يفكّر ← 02 الاقتراحات ← 06 رحلتك الآن ← 06b إشعار التأخير ← 07 التنبيه ← 08 طريق أسرع ← 09 وصلت`

شاشات الأسئلة: `03 اختر طريقتك` و`04 لماذا لا نوصي بالخيار C؟` و`05 خطوات الرحلة`.

- في الشاشة 06 يظهر إشعار التأخير تلقائيًا بعد 6 ثوانٍ.
- عند فتح **لوحة المحاكاة** يتوقف الإشعار التلقائي، ويتحكم الفريق بالتأخير يدويًا.

## النشر على Vercel

1. ارفع المجلد إلى GitHub.
2. ادخل [vercel.com](https://vercel.com) بحساب GitHub، واضغط **Add New ← Project**، واختر المستودع `mihad-web`، ثم **Deploy**.
3. لتشغيل الذكاء الاصطناعي: **Settings ← Environment Variables**، وأضف:
   - `ANTHROPIC_API_KEY` = مفتاح من [console.anthropic.com](https://console.anthropic.com)
4. أعد النشر (**Deployments ← Redeploy**).

> لا تضع المفتاح داخل أي ملف في المستودع.

## ملاحظات

- بيانات الأوقات والازدحام **محاكاة** حاليًا، ومستقبلًا من بيانات المشغّل.
- إذا تعذّر الاتصال بالذكاء الاصطناعي، يرد المساعد تلقائيًا بالوضع الاحتياطي حتى لا يتوقف العرض.
